# Code of conduct

MoonLib is a small project and we want it to stay a friendly place to ask questions and contribute.

**Expected:** be patient with newcomers, assume good intent, keep feedback about the code rather than
the person, and say thanks.

**Not accepted:** harassment, insults, discrimination of any kind, personal attacks, sharing someone's
private information, and repeatedly pushing a point after a maintainer has asked you to stop.

**Enforcement:** maintainers may edit or remove comments, close issues, or block people who break
these rules. Report problems privately to the maintainers through the contact on the GitHub profile
of the repository owner. Reports are handled confidentially.
